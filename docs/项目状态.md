## 主流程

```
用户输入
  ↓
任务解析 → TASK_<n>
  ↓
任务落盘 (data/tasks/)
  ↓
候选生成 → TMP_<n>
  ├─ LLM + 文献 RAG
  ├─ CASE_TRANSFER
  └─ DOE
  ↓
代理模型初筛
  ↓
ABAQUS 校核 → C<n>
  ↓
知识回流 → CASE_<n>
  ├─ data/cases/ (所有样本)
  ├─ knowledge/case_library/ (仅通过样本)
  └─ 案例向量库
  ↓
报告生成
```

---

## 关键特性

### 1. 编号独立
- 任务编号与样本编号独立递增
- 任务编号反映会话次数
- 样本编号反映样本总数

### 2. 数据精简
- 候选数据仅保留必要字段
- 无冗余标识字段
- 结构清晰统一

### 3. 追溯能力
- case 记录包含 `task_id`
- 可追溯样本来源于哪次会话
