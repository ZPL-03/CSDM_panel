# CSDM_panel 项目状态

## 能力与职责

系统支持 T、BLADE、L、HAT 四类复合材料加筋壁板。LLM 负责带原文证据的需求抽取与工程评议；程序负责候选数量、各筋型配额、唯一性、几何与铺层、FEM 输入、结果关联及推荐比较。

候选来源为 CASE_TRANSFER 和 DOE，配置初始比例为 1:1。案例迁移按结构化硬条件选择通过样本，案例记忆只辅助排序。所有候选经过统一规则和任务约束，物理重复项不进入候选池；数量不足时报错。

## 物理与代理

求解使用逐层 `CompositeShellSection`、单层 LAMINA 材料、局部材料方向、自平衡蒙皮边牵引及固定中面 Tie。HAT 两侧连接板位于腹板外侧。成功结果保留实际层序、材料、几何、工况、边界与求解代码指纹。

`BLF_global` 为首个正屈曲特征值，不表示完成整体模态识别；未知局部模态和失效类型保持 `null`。线性屈曲不证明材料损伤、缺陷或非线性极限承载。

代理版本为 `panel-physical-v3-type-isolated`。四筋型均使用 101 维输入，分别训练、存放权重并独立验收；同维度不允许跨筋型复用。当前没有可投入预测的独立验收权重，`models/` 可为空。缺模型、不兼容、未验收或域外均不返回预测，默认按生成顺序执行任务指定数量的直接 FEM。

完整知识只存运行资产，不复制原文解析、SFT、适配器或重复向量。全部关系检查证据块身份、来源、指纹、用途及适用条件。

报告使用完整 RAG/KG 证据上下文。检索内容去重，同一来源最多两个块。引用按 DOI、来源编号和 URL 合并；同名文献副本的已知 DOI、年份无冲突时也合并，章节标题不作为文献身份。正文、公式、表格与条件不截断，预算不足则整块排除并记录原因。模型通过绑定事实解释推荐判断、方案取舍与验证事项，数值只来自当前任务及 FEM。

总体报告包含完整候选池、送检依据、实际校核结果、最终推荐与去重文献引用。最终推荐整合数值比较、推荐判断、方案取舍及针对性验证。内部检索契约与完整原值保存在事实 JSON，不进入正文。Markdown、PDF 和事实 JSON 成组生成；启用 LLM 时，API 或评议校验失败中止导出。最小重量按面密度乘投影面积比较，最小面密度使用面密度；缺少直接刚度指标时不以 BLF 替代刚度。见 [工程设计报告](工程设计报告.md)。

## 桌面界面

黑灰主题普通窗口启动，大小按显示器可用区域确定，不强制最大化。左侧按钮、输入固定可见，摘要与对话独立滚动；右侧表格占工作区整行，详情与三维视图可调整比例。

源码仓库为 `ZPL-03/CSDM_panel`。

## 验证入口

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -CheckEnvironment
conda run -n AGENT --no-capture-output python -X utf8 -B -m pytest tests -q --run-real-fem -p no:cacheprovider
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/sync_external_knowledge.py --verify-only
```

API、层序和 mechanics 使用 `scripts/validate_physical_workflow.py` 与项目外独立输出目录。通过状态必须对应实际输入、代码、工件和非空报告；默认 pytest 的跳过项不算真实 FEM 验收。力学判据及模型边界见 [物理模型与集成验收](物理模型与集成验收.md)。

四筋型 API 样本的首个正特征值为：T `3.57`、BLADE `2.81`、L `3.58`、HAT `4.52`。这些值仅对应当前验收样本，不表示全参数域精度。

每类 API 流程包含 2 个候选、1 个实际校核结果、1 个成功求解和非空 Markdown、PDF、事实 JSON。代理模型不可用时按生成顺序直接进入 FEM；当前结果只支持对应载荷、边界、几何、铺层和理想 Tie 模型下的线性屈曲比较，不表示全参数域最优或缺陷敏感性结论。

报告工件包括 Markdown、PDF、事实审计与 `acceptance.json`，并记录源文件及代码 SHA256。拒绝响应与复核问题按实际情况保留，模型接受状态不代替工程师审阅。

本机桌面在 1000×640、1280×800、1440×900 下完成原生截图检查，左侧 11 个按钮均可见，三维场景非空并响应相机交互。初始窗口不强制最大化。
