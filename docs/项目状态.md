## 主流程

```
用户输入
  ↓
任务解析 → TASK_<n>
  ↓
任务落盘 (data/tasks/)
  ↓
候选生成 → TMP_<n>
  ├─ LLM + 外部知识库/知识图谱
  ├─ CASE_TRANSFER（结构化硬过滤 + 案例记忆向量排序）
  └─ DOE
  ↓
代理模型初筛
  ↓
ABAQUS 校核 → C<n>
  ↓
知识回流 → CASE_<n>
  ├─ data/cases/ (所有样本)
  ├─ knowledge/case_library/ (仅通过样本)
  └─ 案例记忆向量索引
  ↓
报告生成
```

## 关键特性

### 1. 编号独立
- 任务编号与样本编号独立递增
- 任务编号反映会话次数
- 样本编号反映样本总数

### 2. 数据精简
- 候选数据仅保留必要字段
- 无冗余标识字段
- 结构清晰统一

### 3. 外部知识库/知识图谱增强
- 外部知识库/知识图谱资产已放置在本项目内部
- CSDM_panel 运行时不直接读取参考项目路径
- 外部知识库/知识图谱目录已加入 `.gitignore`

### 4. 追溯能力
- case 记录包含 `task_id`
- 可追溯样本来源于哪次会话
