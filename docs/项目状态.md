# CSDM_panel 项目状态

## 能力与职责

系统支持 T、BLADE、L、HAT 四类复合材料加筋壁板。LLM 负责带原文证据的需求抽取与报告事实选择；程序负责候选数量、各筋型配额、唯一性、几何与铺层、FEM 输入及结果关联。

候选来源为 CASE_TRANSFER 和 DOE，配置初始比例为 1:1。案例迁移按结构化硬条件选择通过样本，案例记忆只辅助排序。所有候选经过统一规则和任务约束，物理重复项不进入候选池；数量不足时报错。

## 物理与代理

求解使用逐层 `CompositeShellSection`、单层 LAMINA 材料、局部材料方向、自平衡蒙皮边牵引及固定中面 Tie。HAT 两侧连接板位于腹板外侧。成功结果保留实际层序、材料、几何、工况、边界与求解代码指纹。

`BLF_global` 为首个正屈曲特征值，不表示完成整体模态识别；未知局部模态和失效类型保持 `null`。线性屈曲不证明材料损伤、缺陷或非线性极限承载。

代理版本为 `panel-physical-v3-type-isolated`。四筋型均使用 101 维输入，分别训练、存放权重并独立验收；同维度不允许跨筋型复用。当前没有可投入预测的独立验收权重，`models/` 可为空。缺模型、不兼容、未验收或域外均不返回预测，默认按生成顺序执行任务指定数量的直接 FEM。

完整知识只存运行资产，不复制原文解析、SFT、适配器或重复向量。同步入口从 CS_LLM 的 `dataset/processed/rag_kg_runtime/csllm` 验证后整体替换目录。全部关系检查证据块身份、来源、指纹、用途及适用条件。

报告使用完整 RAG/KG 证据上下文。检索内容去重，同一来源最多两个块。引用按 DOI、来源编号和 URL 合并；同名文献副本的已知 DOI、年份无冲突时也合并，章节标题不作为文献身份。正文、公式、表格与条件不截断，预算不足则整块排除并记录原因。报告事实来自当前 FEM，模型只选择已有事实引用及适用建议，不能填造数值。

总体设计方案报告包含完整候选池、送检依据、实际校核结果、最终推荐、关键事实、验证建议和去重文献引用。内部检索契约与完整原值保存在事实 JSON，不进入正文。任务目录内成组保存 Markdown、PDF 和事实 JSON；启用 LLM 时，API 或事实校验失败直接中止导出。推荐由程序计算，最小重量使用面密度乘投影面积的质量，最小面密度使用面密度；缺少直接刚度指标时不以 BLF 替代刚度排名。

## 桌面与部署

黑灰主题普通窗口启动，大小按显示器可用区域确定，不强制最大化。左侧按钮、输入固定可见，摘要与对话独立滚动；右侧表格占工作区整行，详情与三维视图可调整比例。

本机路径为 `D:\Project\VS_Code\CSDM_panel`，工作站路径为 `D:\Project\CSDM_panel`。两端使用各自 `.env` 与 Abaqus 安装，代码、配置和知识文件一致。正式数据、失败证据与求解原件保留；机器配置不参与覆盖。源码仓库为 `ZPL-03/CSDM_panel`，外部知识通过独立发布附件提供。
