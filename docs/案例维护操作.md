# 案例维护操作

## 目的与环境

本指南用于生成逐层 FEM 案例、重建案例检索索引和补齐求解工件。命令在项目根目录执行，使用本机 Conda `AGENT` 环境。生成与工件重建调用真实 Abaqus；索引更新使用 CPU BGE-M3，不调用外部 LLM。代理训练是独立操作。

## 批量生成

任务模板 `reference/physical_doe_task.json` 指定四筋型、`360×300 mm`、轴压 `120 kN/m`、SSSS、T300/5208、8 mm 网格与 16 个屈曲模态。材料值来自项目材料库；未提供 G13/G23 时沿用物理模型指南中的横向剪切假设。其他几何与铺层在任务允许域内按 DOE 采样。该模板不是所有几何的网格精度保证。

先执行四个候选，每种筋型一个，检查输入、工件和实际耗时：

```powershell
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/build_initial_cases.py --task-json reference/physical_doe_task.json --count 4 --seed 42 --workers 1
```

指定不同种子可生成下一批候选。`--count` 为全部任务的总数，按任务均分，多余名额依次分配；数量不得小于任务数。

```powershell
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/build_initial_cases.py --task-json reference/physical_doe_task.json --count 40 --seed 1042 --workers 1
```

参数模式要求显式指定筋型、载荷类型、两个载荷分量和边界，无载荷的分量填 `0`。材料默认 `T300_5208`，几何包络来自各筋型参数配置，通常不同于上述固定尺寸模板。

```powershell
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/build_initial_cases.py --stiffener-types T BLADE L HAT --load-type compression_shear --nx 120 --nxy 60 --boundary SSCC --material T300_5208 --count 40 --seed 2042 --workers 1
```

任务 JSON 可为完整任务对象或含 `task` 的封装；`--task-json` 可重复指定。允许筋型列表会拆成独立任务，每种保留相同工况、材料和几何约束。任务中 `material_system.is_user_specified=true` 固定该材料；`false` 或未提供时按 DOE 的材料目录采样。`analysis` 对象传入候选，网格和模态数参与物理输入校验。JSON 模式不能混用参数模式的载荷、边界或材料选项。

`--seed` 显式指定 DOE 随机种子，各任务依次加一；未指定时读取项目配置。任务记录保存实际种子。采样使用用户任务约束和 `config/param_ranges.yaml`，固定参数保持原值。几何检查要求 HAT 帽顶宽度小于底部腹板跨度，完整截面足迹不越板且相邻筋不重叠；HAT 比例和倾角限制读取 `HAT_constraints`，属于可配置设计约束。不同种子不替代训练与独立验收记录的物理设计去重。

执行顺序为：校验全部任务、生成并验证整批候选、分配编号、保存任务、提交 FEM、归档案例。提交时保留已校验的候选材料、铺层、几何和分析参数。已有任务不覆盖；失败结果保留明确状态，整体退出码非零。此入口不重置数据，不训练代理。FEMAgent 负责作业锁和正式工件清理，保留 CAE、INP、ODB、物理输入及结果中的诊断。

写入范围：`data/tasks/`、`data/io/`、`data/abaqus_runs/`、`data/cases/`、`knowledge/case_library/`、案例 Chroma。外部知识包与项目外验收目录不写入。

## 索引重建

```powershell
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/rebuild_case_memory.py
```

读取 `data/cases/CASE_*.json` 和 `knowledge/case_library/CASE_*.json`。案例身份、候选来源、任务、物理输入、层序比例及结果状态先完成校验；必要字段缺失、未知来源、非有限数值、身份错配或正式/评估档案冲突时停止，索引不更新。正式案例须为成功且通过的结果。

所有记录通过后，计算整批摘要嵌入并写入索引，再删除不属于当前案例集合的索引项。不清空集合，不改写案例、任务、I/O 或求解 JSON，不补历史 `analysis_contract`。空来源拒绝更新；嵌入和索引异常向调用者暴露。来源完整不表示结果符合当前代理训练条件。

## 工件重建

```powershell
conda run -n AGENT --no-capture-output python -X utf8 -B scripts/rebuild_abaqus_artifacts.py --case-id CASE_1 --workers 1
```

仅在成功结果同时具有有效 INP 和 ODB 文件时跳过。`--case-id` 与 `--candidate-id` 可重复指定，组合使用时取交集；不存在的指定编号报错。`--limit` 限制提交数量，`0` 表示全部选中且需要重建的记录。

`--force` 即使工件存在也重新求解；维护入口先将正式运行目录及 I/O 原件移至项目外 `CSDM_panel_solver_archive/`，保留原始字节，不预先删除案例或索引。入口严格读取既有设计，不用任务材料覆盖候选材料，不把未知来源改为 DOE，不补必要物理输入；归档设计的展示标识取既有候选编号。整批选中记录先验证，再启动求解。

结果回写对应评估档案、正式案例状态、I/O 和单条案例索引。失败不保留先前的“通过”结论；缺失或无效输入在求解前报错。该操作会更新指定案例的求解结果，执行前应确认目标编号与所需物理模型版本。

## 代理训练与使用

正式入口为 `scripts/train_screener.py --stiffener-type T`，必须明确 T、BLADE、L 或 HAT；训练数据目录可通过 `--cases-dir` 指定，权重目录可通过 `--models-dir` 指定。独立验收使用 `--validate-cases`、`--max-mape`、`--max-relative-error` 和 `--min-per-slice`。训练、留出与独立验收按物理设计分离；误差阈值在验收前确定。

`panel-physical-v3-type-isolated` 包含筋型独热编码、适用几何、材料及各部件 A/B/D，共 101 维。每种筋型分别训练 RF，在 `models/<筋型>/` 保存权重、来源与独立验收，按载荷类型和边界建立训练包络及验收切片；未验收切片或域外输入不能预测。切片验收范围由实际训练数据确定，不自动等于全部 36 种组合。没有兼容且通过验收的权重时，编排按 `direct_fem` 路径选择任务规定数量的候选直接求解，并保存原因和选择顺序，不生成代理 BLF 或性能排名。

### 适用性判定

几何特征包含十个参数，HAT 帽顶宽度和厚度单独编码；不适用部件的几何及 A/B/D 为零，四项类型独热编码区分 T 与 L 等参数名相同、装配不同的截面。材料参数包含 G13/G23，载荷分量与边界同时进入特征。特征维度相同不表示权重可互换；训练和独立验收必须仅包含指定筋型，类型标识与候选不符时拒绝预测。

现有切片检查是使用条件，不是全参数域精度证明：

- 分组留出防止同一物理设计跨训练和留出，但未保证每个切片在训练集中有足够设计；没有训练包络的切片不可用。
- 逐特征最小值/最大值包络不能证明几何、材料和载荷比例的联合覆盖；独立设计应覆盖预期使用域及其边界。
- 独立验收要求每个训练切片至少两个不同设计，同时检查平均与最大相对误差；这只是入口的最低数量限制，不能代替应用所需的采样设计。
- 网格尺寸与模态数不进入特征，样本准入也不读取收敛或模态审查记录。训练前应统一目标定义并核对相应网格、连接与模态证据。
- 分组指纹包含完整几何对象，特征仅使用该筋型必需字段。外部样本携带不适用几何键时，应核对物理等价性，避免等价设计因额外字段分到不同组。

每切片只有一个设计的种子案例不满足独立验收数量要求，也不提供训练集之外的精度证据。权重保持缺失时，使用 `direct_fem`。
